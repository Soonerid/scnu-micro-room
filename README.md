# 微格预约助手 · 共享版

> **只约真正需要的时间，把空闲留给更多人。**
>
> 为个人练习和空位发现而做。请按实际需要选择时段，约到就停；临时不用请提前取消，到场按规则签到。不要用来囤积课室、替他人批量占位或长期占用公共资源。

华南师范大学微格教室的 Windows 本地助手。每个人在自己的电脑填写自己的学校账号。它不是学校官方产品，不保证预约成功，也不会绕过学校限额、验证码或限流。

![首次启动：填写本人账号，默认暂停预约](docs/first-start.png)

## 给舍友的三步说明

1. 从本仓库 **Releases** 下载 `微格预约助手共享版.zip`，**全部解压**到一个准备长期保留的文件夹。
2. 双击 **`Install-and-Open.cmd`**。第一次会准备 Node.js 运行环境、创建桌面快捷方式并打开面板；如需下载，只从 [Node.js 官方下载站](https://nodejs.org/en/download)获取并校验 SHA-256。
3. 填写**自己的学校统一认证账号和密码**并验证，选择真正需要的校区、日期和时段，再启用自动预约。首次安装默认暂停，不会填完账号就直接占位。

以后双击桌面“微格预约助手（共享版）”或 `Open.cmd`。本机页面地址是 `http://127.0.0.1:8912/`。Windows 10/11，Node.js 22 或更新版本；没有现成运行环境时安装脚本准备 Node.js 24 LTS。电脑须开机、联网并保持当前 Windows 用户登录。关闭网页后后台继续运行；关机时不能预约。

## 能做什么

- 浏览石牌、大学城课表，按上午／下午／晚上查看空位。
- 按本人偏好申请：同一教室连续两节优先，下午先找15:00后的组合，也可接受单节。
- **默认仅预约指定的一天，成功后自动暂停**，减少忘记关闭导致的多余预约。确需日常练习时，可主动改为“每天新放出的日期”；校方放号配置以实际回读为准。
- 放号起20分钟内持续尝试；晚间至午夜每5分钟、白天09:00—18:00每10分钟检查余位，其他时段不安排捡漏。遇到平台限流会退避。
- 已有目标日期预约就跳过，成功后停止该日后续申请；服从学校总节次上限。未知提交结果先核验，不盲目重发、不自动替换已约教室。
- 预约成功回读确认后，在右下角静音提醒，不发声、不抢焦点。

**不用了先暂停助手，再去官网取消预约**，避免后台又申请到同一天的空位。平台公告要求预约开始后10分钟内签到，连续预约首节缺席会影响后续节次；具体以[学校正式公告](https://tstc.scnu.edu.cn/#/notice/preview?id=8)为准。

## 账号与数据

- 仓库和下载包不含原使用者的账号、密码、登录会话、预约记录、观察名单、个人截图或运行日志。
- 输入只发送给本机后台，再向学校统一认证系统验证；不上传 GitHub，不使用远程公共服务器。
- 密码和会话用 Windows 当前用户 DPAPI 加密，保存在 `%LOCALAPPDATA%\SCNU-MicroRoom-Community`，不是放在下载的程序文件夹里。不要分享这个数据目录，也不要共用一个 Windows 账号。
- 课表只展示学校已向登录用户返回的姓名，不展示其他人的学号、联系方式。**七天姓名观察默认关闭**，避免每个使用者都重复采集名单；如确有需要，可在观察页自行启用，数据仅留在本机。
- 账号验证失败不会覆盖已保存的账号；需要验证码时到官网处理。更新密码前先暂停预约。
- 软件不调用大模型，不需要 OpenAI/Codex，不消耗其 token；这里也不包含任何 Codex 定时跟进。

## 开发与核验

无需安装 npm 依赖：`npm test` 运行本地测试，`npm start` 启动面板。测试使用虚拟账号和模拟学校响应，不提交真实预约。安装目录不要移动；移动后重新运行安装脚本更新路径。

学校接口、页面和规则可能调整。登录或课表读取失败会明确提示；发现不符时暂停预约并核对官网。请只反馈去掉个人信息后的问题，不上传密码、token、DPAPI 文件或姓名观察数据。
